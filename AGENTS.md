# Project Instructions

## Commit provenance

- Use only the repository owner's configured human identity for commit authors,
  committers, and taggers.
- Do not add secondary authorship or attribution trailers (for example
  `Co-authored-by`) unless the repository owner explicitly requests them.
- Before every commit, tag, or push, audit Git object headers, message trailers,
  notes, hooks, relevant configuration, and pull-request metadata.
- Do not rewrite or move a published tag without the repository owner's explicit
  authorization.
